# RuralCare – Centralized Medical Records Platform

🌐 **Live Website:** https://ruralcare-five.vercel.app/

## About the Project
RuralCare is a healthcare platform that helps patients and doctors manage medical records online.

## Features
- Patient and doctor registration and login
- Patient medical records
- Doctor medical report uploads
- Medical report access for patients
- Online healthcare record management

## Technologies Used
- Frontend: React and Vite
- Backend: Node.js and Express
- Database: MongoDB
- Deployment: Vercel and Render
